# Preguntas para el docente

Estas dudas se resuelven en la clase del jueves. Mientras tanto, el proyecto avanza con las decisiones que ya están claras.

1. **Despliegue:** ¿la demo puede ser local con Docker Compose, o se requiere una URL pública? Si se requiere, ¿se puede usar Vercel para el frontend con una base de datos en la nube?
2. **Asistente con API externa:** ¿es aceptable usar una API de IA en la nube (Groq) en lugar de un modelo local? ¿Hay restricciones sobre qué datos se envían?
3. **Datos simulados:** ¿es válido simular cambios sobre WideWorldImporters para demostrar la carga incremental y disparar alertas, siempre que se identifiquen como simulación?
4. **Alcance:** ¿el recorte propuesto (un proceso de ventas, SCD Tipo 2 solo en cliente, dos reglas de alerta) cumple con los requisitos mínimos?
5. **Formato de entrega:** ¿la documentación debe entregarse en Word con APA 7, en PDF, o como repositorio con README?
6. **Versión de SQL Server:** ¿hay preferencia por SQL Server 2022, o se acepta otra versión?
